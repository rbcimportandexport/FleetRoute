# FleetRoute

The frontend is intentionally blank and ready for a new design.

## Frontend

```bash
npm install
npm run client
```

Production build:

```bash
npm run build
```

The GitHub repository and Vercel project configuration are preserved. Existing UI components, styles, media, APK, and Android presentation assets have been removed.

The backend source remains in `server/` for future use and is not called by the blank frontend.
